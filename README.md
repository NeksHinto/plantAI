# PlantAI: Sistema de Cuidado y Monitoreo de Plantas

## Descripción del Proyecto
Este proyecto consiste en una aplicación web orientada al seguimiento, organización y cuidado automatizado de plantas del hogar en base a su ubicación física. El sistema permite clasificar las especies según las habitaciones o ambientes donde se alojan (Living, Balcón, Dormitorio, etc.), evaluar su estado de salud y registrar un historial de recomendaciones clínicas botánicas.
